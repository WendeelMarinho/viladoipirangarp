Destaques do gamemode

Resumo derivado do catálogo do servidor e da documentação dos sistemas enterprise/premium. O servidor em produção carrega o que o oStarter inicia (e recursos com symlink em mods/deathmatch/resources/).

Núcleo OriginalRP (produto RP)

  • Conta e personagem: oAccount, oSync, whitelist (oWL / oCore), oDashboard, níveis (oLvl), licenças (oLicenses).
  • Comunicação e UI: chat RP (oChat), telefone (oPhone), HUD/radar/velocímetro (oHud, oRadar, oSpeedo), inventário DX (oInventory), nametags (oNametag).
  • Economia: salários (oPayday), banco (oBank), lojas e mercado (oShop, oMarket), trabalhos (oJob, oJob_*), multas (oTicket).
  • Veículos: posse e sync (oVehicle), concessionárias (oCarshop), tuning e pinturas (oTuning, oPaintjobs), combustível (oFuel), handling (oHandling) — e oCVEH, painel por modelo para portas e componentes no veículo.
  • Facções e mundo aberto: oFactionScripts (algemas, grab, reviver médico), oDeath, interiores/imóveis (oInteriors), mapas custom ligados pelo starter.

Sistemas premium recentes (facções & ilegalidade estruturada)

  • oFactionScripts: gameplay de facção — algemas (item 77), grab com attach sincronizado, reviver com kit (81) e animação ~8 s; exports como isInLawEnforcementDuty / isInMedicalDuty para integrações.
  • oWanted: níveis 1★–5★, crimes tipados (fuga_policial, homicidio, etc.), bounty, decaimento automático nos níveis mais baixos, HUD e blip para polícia em serviço, persistência em DB.
  • oTerritory: captura de zonas em tempo real, estado contestado, rendimento horário para facção.
  • oFactionHQ: HQ por facção — portões, ponto de munição, spawn de viaturas de serviço (configuração in-game via comandos admin; ver pendências abaixo).
Staff: estes quatro recursos estão integrados no código e na ordem do starter; falta configuração completa in-game (HQ por facção, territórios, e algumas integrações listadas em next-actions.md).

Fase 4 — visão geral

A Fase 4 agrupa sistemas sociais, criminalidade estruturada, progressão, justiça IC e conteúdos civis. Os recursos arrancam na ordem definida pelo oStarter (dependências entre scripts).

  • Social / UX: tags IC, chat estendido (Twitter IC, Deep Web, proximidade), boas-vindas, rankings.
  • Economia ilegal: furto de veículos (gazua, chop, seguro, GPS), assaltos a pontos fixos (ATM, lojas, joalharia).
  • Legal / meta: reputação por facção, evidências forenses, tribunal (OAB), eleições municipais, jornal IC.
Dica: Mensagens ao jogador são em PT-BR. Painéis seguem convenções do servidor (ex.: Backspace para fechar onde aplicável, cursor em pares com painéis DX).

Jogador oTags

Sistema de tags IC (facções, eventos, raridade), sincronização com personagem e impacto visual no nome / chat conforme integrações.

  • Nametag e prefixos cooperam com oChat / oRank (badge de ranking quando configurado).
  • Administradores gerem tags via comandos dedicados (ver secção Admin).

Jogador oChat3

Extensões ao chat: Twitter IC, Deep Web (zonas e item de dispositivo), tons de proximidade, sussurros e teclas que não conflituam com outros painéis.

  • Uso de Y / teclas conforme bind do servidor para Twitter e fluxos IC.
  • Deep Web com requisitos de localização ou item encriptado (ver recurso e infobox no jogo).

Jogador oWelcome

Ecrã de boas-vindas no login (notícias, dicas, atalhos), opção de não voltar a mostrar e reabertura por comando.

ComandoDescrição

Jogador oRank

Rankings por categorias, cache no servidor, temporada ativa e estatísticas persistidas.

Comando / açãoDescrição

Outros sistemas (furto, assaltos, média, etc.) incrementam estatísticas via servidor — não é necessário comando para “submeter” pontos.

Jogador oCarTheft

Roubo de veículos privados com gazua (item 169 — nome no inventário pode variar), alarme, modo seguro após falhas, chop shop, seguro, GPS e detector.

Itens principais

  • 169 — gazua / ferramenta de arrombamento (uma tentativa por uso).
  • 248 — rastreador GPS (instalar no teu veículo).
  • 249 — detector de rastreador (dentro de veículo roubado).

Como jogar (resumo)

  1. Aproxima-te do veículo alheio (não facção / não temporário / não protegido) e usa clique direito para pedir arrombamento (validação no servidor).
  2. Completa o minijogo (faixa verde + Espaço); falhas podem disparar alarme e, após várias falhas, modo seguro temporário no veículo.
  3. Com sucesso, conduz até um desmantelamento autorizado e usa /desmantelar (minijogo longo no cliente).
  4. Seguro: após o veículo ser processado no chop, o dono pode usar /seguro para ver sinistros e reclamar (UI com Backspace para fechar).
ComandoDescrição
/seguroPainel de sinistros / reclamação de seguro.
/desmantelarInicia fluxo de chop no ponto válido (condutor, veículo roubado pelo teu personagem).
/instalarrastreadorAjudante para instalar GPS no teu veículo próximo.
/detectorrastreadorUsa o detector estando dentro do carro roubado.
Admin: /addchopshop [org_id] [nome] — regista chop na posição actual (interior/dimensão). Ver tabela admin abaixo.

Jogador oHeist

Assaltos a locais fixos (ATM, loja de conveniência, joalharia) com fases de minijogo (hacking e furadeira), grupo mínimo conforme o local, cooldown por local e alerta à polícia.

  • Aproxima-te do marcador no mundo e pressiona E para iniciar (és o líder da sessão).
  • Tipos diferentes exigem número mínimo de assaltantes por perto (fora de serviço policial).
  • Cancelar minijogo: Backspace (onde aplicável).

Início do assalto: aproxima-te do marcador cilíndrico no mapa e pressiona E. O líder executa os minijogos (hack / furadeira) quando o servidor enviar cada fase.

Admin: /addheistspot [tipo atm|store|jewelry] [reward_min] [reward_max] [cooldown_min] [min_players] [alerta 1-5] [nome…]

Jogador oElections

Eleições municipais em ciclo campanha → votação → encerramento. Vencedor é anunciado no chat; promoção automática a cargo na Prefeitura (facção 76) pode exigir passo manual do staff.

Jogador oMedia

Publicação de notícias IC: mensagem global no chat e cópia física no inventário (item 250 — Jornal IC), com cooldown entre publicações.

ComandoFormato

O valor do item guarda JSON (título, corpo, autor, ids e tempo) para leitura/tooltip conforme o inventário.

Administração Visão geral

Estes comandos complementam o RP e a operação do servidor. Os níveis de admin (user:admin) indicados são os usados nos scripts desta fase; confirma sempre a tua ACL interna e o guia-administracao-completo.md.

  • Nível 6: vereditos de tribunal (absolver / culpar).
  • Nível 7: chop shop, pontos de heist, eleições, reputação admin, entre outros.

Bases de dados: cada recurso cria ou usa tabelas próprias (CREATE TABLE IF NOT EXISTS). Mantém cópias de segurança antes de alterações manuais.

Integrações e arranque

  • oStarter: ordem canónica inclui oTags → oChat3 → oWelcome → oRank → oVehicle → oCarTheft → oHeist → … → oReputation antes de oWanted → oEvidence → oTribunal → oElections → oMedia → …
  • oWanted + oReputation: prisão (clear wanted normal) aplica deltas de reputação; absolvição judicial usa modo tribunal sem bounty/rep de prisão.
  • oHeist / oCarTheft → oEvidence: eventos geram registos forenses automáticos (assalto / alarme).
  • oRank: stats como carros_roubados, roubos_realizados, eleicoes_vencidas, noticias_publicadas, etc., conforme cada recurso.
  • Premium: oFactionScripts → oWanted → oTerritory → oFactionHQ → oInteraction (ordem documentada em sistemas-premium.md).

Symlinks: em mods/deathmatch/resources/ existem ligações simbólicas para vários recursos da pasta vila-do-ipiranga-rp — útil para deploy e ACL.

Próximas melhorias e trabalho pendente

Sim — há trabalho explícito na fila operacional e técnica. Lista condensada a partir de docs/worklog/next-actions.md (2026-05-03); detalhes e SQL exemplificativo ficam no Markdown.

Alta prioridade — configuração in-game

  • HQ por facção: para cada facção com HQ: /hqsetup, /hqammo, /hqgate, /hqveh (IDs 74–83 documentados no next-actions).
  • Territórios: validar zonas seed com /tp; ajustar allowed_types / min_members na DB se necessário para testes ou regras de captura.

Alta prioridade — integrações de código

  • oGate + oFactionHQ: antes de abrir portão, validar exports.oFactionHQ:canOpenGate(player, gateID).
  • oDeath + oWanted: morte por policial em duty → registar crime (ex.: homicídio) via exports.
  • oFactionScripts + oWanted: ao prender na cela — disparar limpeza de wanted / pagamento de bounty conforme API do recurso.

Média prioridade

  • ACL oAdmin: garantir resource.oAdmin no grupo Admin em acl.xml (servidor parado).
  • QA login/registo após o fix ACL.
  • Stubs oFactionScripts: stinger, speedcam móvel, RBS/mangueiras/tambores — muitos ainda “em desenvolvimento”.

Evolução de produto (roadmap / enterprise)

  • Aprofundar oReputation (efeitos em preços/acesso), oEvidence (mais tipos de vestígio), oTribunal (sala/interior, tempos IC), oElections (promoção automática na facção 76 quando API estável no dashboard), oMedia (rádio IC, vínculo a profissão).

Baixa prioridade / backlog técnico

  • Traduzir restos húngaros em oPayday; optimizar queries em oAccount; limpar duplicados oNewPD no starter; remover referências a recursos inexistentes no timer retardado; dívidas TD-SEC/TD-ARCH referenciadas no next-actions.
