# ecc-memory — memória do projecto

## Ficheiro principal

- **`.cursor/memory/project-state.md`** — sprint, marcos, próximos passos, sistemas protegidos.

## Quando actualizar

- Ao fechar um marco (sprint, release, migração).  
- Quando mudar prioridade em `docs/worklog/next-actions.md` (espelhar o essencial aqui).

## Não substitui

- `docs/worklog/current-sprint.md` (histórico formal)  
- `.cursor/context/current-sprint.md` (contexto Cursor detalhado)

Mantenha os três **coerentes** após mudanças de plano.
